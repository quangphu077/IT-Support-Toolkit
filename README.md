# IT Support Toolkit

A collection of PowerShell tools designed to support daily IT Operations and Infrastructure troubleshooting.

## Project 1: Network Diagnostic Tool

A Windows PowerShell GUI application for collecting network configuration and troubleshooting connectivity issues.

### Features
- Network Adapter Information
- IP Address and Subnet Mask
- Default Gateway
- DNS Server Information
- DHCP Configuration
- Gateway Connectivity Test
- Internet Connectivity Test
- DNS Resolution Test
- Export Diagnostic Report to TXT

### Requirements
- Windows 10 / Windows 11
- Windows PowerShell 5.1 or PowerShell 7
- Windows Forms support

### How to Run

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Network-Diagnostic-GUI.ps1"
```

### Technologies
- PowerShell
- Windows Forms
- Windows Networking Commands

### Purpose
This project demonstrates practical PowerShell scripting, AI-assisted development, network troubleshooting, and IT automation.
